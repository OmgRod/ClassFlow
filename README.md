# Misplace No More

A Flutter app to help you track where you put your items so you never misplace them again!

## Features

- **Add Items**: Track any item by giving it a name and specifying its location
- **Found/Lost Status**: Mark items as found or lost to keep track of what you're looking for
- **Delete Items**: Remove items you no longer need to track
- **Clean UI**: Material Design 3 interface that's easy to use

## Getting Started

1. Make sure you have Flutter installed on your machine
2. Clone this repository
3. Run `flutter pub get` to install dependencies
4. Run `flutter run` to start the app

## Usage

1. Tap the **+** button to add a new item
2. Enter the item name (e.g., "Keys", "Wallet", "Phone")
3. Enter where you put it (e.g., "Kitchen drawer", "Desk")
4. Tap **Add** to save the item
5. Use the search icon to toggle an item between Found/Lost status
6. Use the delete icon to remove an item from tracking
